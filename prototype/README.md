# MuchWalk prototype

A clickable UI prototype for **MuchWalk**, a Doge-themed move-to-earn app we're building on **DogeOS** (Chikyū testnet).

**Live:** https://srimadhavsats.github.io/dogeos_stepwalk/

Everything runs in the browser with fake data. Nothing connects to a wallet, and nothing is saved.

## Try this
1. Tap **🐾 +1,000 steps** twice for the goal confetti. Tap once more to level up.
2. **Pup** tab: evolve Biscuit and try on gear.
3. **Walk**: start a run, switch on **Go Live**, and tap 🔊 to hear Coach Bark read tips aloud.
4. Ask Coach: *"Should I buy more TREAT?"*
5. **Moon** tab: the live Walk Block feed (real 10-minute windows).

On a phone it opens full-screen. On a computer it shows inside a phone frame.

## Run locally
Open `index.html` in any modern browser. There's no build step and no dependencies apart from Google Fonts.
